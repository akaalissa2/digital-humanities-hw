# Домашнее задание №1. Полнота библиографических данных по лингвистике в Open Library

## 1. Исследовательский вопрос

Насколько полно в результатах поиска Open Library по теме лингвистики представлены сведения об авторах, годах первой публикации и языках изданий? Различается ли доля пропусков в сведениях об авторах и языках у произведений разных периодов?

Ответить на этот вопрос можно с помощью библиографических метаданных, которые возвращает Open Library Search API. Для каждого из трёх ключевых полей я рассчитываю количество и долю записей без значения. Дополнительно сравниваю доли пропусков для произведений, впервые опубликованных до 1900 года, в 1900–1999 годах и начиная с 2000 года. Объект исследования — **результаты конкретного поиска в каталоге**, а не вся мировая литература по лингвистике.

## 2. Источник данных

**Источник:** [Open Library Search API](https://openlibrary.org/dev/docs/api/search), запросы к `https://openlibrary.org/search.json`.

Я выбрала Open Library, поскольку каталог позволяет выполнять тематический поиск и получать в структурированном виде именно те сведения, полноту которых я хочу оценить. Open Library — открытый библиотечный каталог проекта Internet Archive. Его записи формируются на основе данных библиотек и других библиографических источников, а также могут дополняться и исправляться пользователями.

**Одна запись в моём наборе — одно произведение (`work`), а не отдельное издание книги.** Оно определяется уникальным полем `key` вида `/works/...`. Одно произведение может быть представлено несколькими изданиями, число которых отражено в `edition_count`. Значения `language` относятся к языкам зарегистрированных изданий и не обязательно обозначают язык первоначального текста.

У источника есть ограничения охвата. В каталоге неравномерно представлены произведения разных стран, языков и эпох: степень подробности записей зависит от того, какие библиотеки и другие участники предоставили метаданные и насколько они впоследствии редактировались. Тематические рубрики тоже не безошибочны: запрос `subject:linguistics` может пропускать релевантные книги и включать работы, лишь косвенно связанные с лингвистикой. Поэтому найденные записи не следует считать полным и безошибочным перечнем лингвистической литературы.

## 3. Сбор данных

Данные собраны на Python в ноутбуке [`hw1.ipynb`](hw1.ipynb) с использованием `requests` и `pandas`. Итоговый набор сохраняется в [`data.csv`](data.csv) в кодировке UTF-8.

**Дата итогового запуска и сохранения набора:** **23.11.2026**. Поскольку ноутбук поддерживает повторное использование сохранённых страниц, часть ответов могла быть получена при предыдущих запусках; точное время получения каждой порции отдельно не фиксировалось.

**Параметры API-запроса:**

| Параметр | Значение |
|---|---|
| Адрес | `https://openlibrary.org/search.json` |
| `q` | `subject:linguistics` |
| `fields` | `key,title,author_name,first_publish_year,language,edition_count` |
| `sort` | `key` |
| `limit` | `2000` |
| `offset` | `0, 2000, 4000, ...` |
| Максимальное число порций | `30` |
| `timeout` | `120` секунд |
| Повторные попытки | До 3 при тайм-аутах, ошибках соединения и ответах `429`, `500`, `502`, `503`, `504` |
| Паузы | 2 секунды после нового запроса; 5 секунд при повторной попытке |
| `User-Agent` | `LinguisticsResearch/1.0` с контактным email, вводимым при запуске |

Функция `get_json()` отправляет запрос, проверяет ошибки и при необходимости повторяет попытку. Цикл пагинации изменяет `offset` и объединяет полученные порции через `extend()` до достижения количества, указанного в `numFound`, либо ограничения числа итераций. В результате было обработано **24 порции**: 23 по 2000 записей и последняя на 1080 записей. Код проверяет полноту каждой порции, общее число строк и отсутствие повторяющихся идентификаторов `key`.

Для защиты от потери результатов ответы порций временно сохраняются в папке `ol_pages/`. При повторном запуске они могут читаться из файлов вместо нового API-запроса. Чтобы собрать актуальную выдачу заново, нужно очистить эту папку перед запуском; её промежуточное содержимое не входит в сдаваемый набор. Из-за обновлений Open Library число результатов при повторном сборе может измениться. Использование API для данного объёма было согласовано с преподавателем.

## 4. Описание данных

В итоговом файле **47 080 строк и 6 столбцов**. Идентификатор `key` уникален во всех 47 080 строках; дубликатов по нему не обнаружено.

| Столбец | Описание |
|---|---|
| `key` | Уникальный идентификатор произведения в Open Library |
| `title` | Название произведения |
| `author_name` | Список имён авторов, указанных в поисковой записи |
| `first_publish_year` | Год первой публикации согласно сведениям каталога |
| `language` | Список кодов языков зарегистрированных изданий |
| `edition_count` | Количество изданий произведения в каталоге |

В исходном ответе API `author_name` и `language` представлены списками; при записи в CSV они сохраняются в виде текстового представления списков. Пропусками при анализе считаются отсутствующие значения, пустые строки и пустые списки.

У **2561** произведения не указан автор (**5,44%**), у **712** — год первой публикации (**1,51%**), у **1904** — язык (**4,04%**). В столбцах `key`, `title` и `edition_count` отсутствующих значений в итоговом CSV не обнаружено. Место издания в выбранном запросе не собиралось, потому что исследовательский вопрос касается авторов, годов и языков, а не географии публикаций.

Отсутствие автора или языка уменьшает число записей, для которых можно изучить соответствующее свойство. Для 712 произведений без года нельзя определить период публикации, поэтому они включены в общую оценку пропусков, но исключены из сравнения по периодам. Наличие значения при этом не гарантирует его исторической точности.

## 5. Предварительный ответ

**Заполненность основных полей в результатах поиска `subject:linguistics`:**

| Поле | Пропусков | Доля пропусков | Заполнено |
|---|---:|---:|---:|
| Автор (`author_name`) | 2561 | 5,44% | 94,56% |
| Год первой публикации (`first_publish_year`) | 712 | 1,51% | 98,49% |
| Язык (`language`) | 1904 | 4,04% | 95,96% |

**Интерпретация (6 предложений).** В собранном наборе лучше всего заполнено поле года первой публикации: оно отсутствует у 1,51% произведений. Чаще всего не указан автор (5,44% записей), а сведения о языках отсутствуют у 4,04%. Таким образом, по выбранным признакам большинство найденных произведений имеют достаточно полные метаданные, хотя заполненность отдельных полей неодинакова. Эти проценты характеризуют прежде всего **то, как Open Library описывает найденные произведения**, а не полноту сведений о лингвистической литературе вообще. Например, отсутствие года в ответе API не доказывает, что действительная дата первой публикации неизвестна, а наличие года не подтверждает его историческую точность. Кроме того, поисковые рубрики и неоднородные источники каталога влияют на состав набора, поэтому результаты нельзя без проверки переносить на все книги по лингвистике.

В ноутбуке дополнительно проведено сравнение произведений разных периодов. Среди 1137 произведений до 1900 года пропуски автора составили 2,02%, языка — 0,53%; среди 21 169 произведений 1900–1999 годов — 6,57% и 3,81%; среди 24 062 произведений с 2000 года — 3,60% и 3,31% соответственно. Неожиданно наименьшая доля пропусков по обоим полям оказалась у самой ранней группы, а наибольшая — у произведений XX века. Это наблюдение не доказывает причинной связи между возрастом произведения и качеством описания: на результаты могли повлиять различия в составе и происхождении записей. Сравнение визуализировано на графике в `hw1.ipynb`.

## 6. Ограничения и следующий шаг

**Тематический отбор.** Поисковая рубрика `subject:linguistics` не гарантирует, что каждое найденное произведение действительно посвящено лингвистике; одновременно некоторые подходящие книги могли не попасть в выдачу. Следующим шагом я бы вручную разметила случайную выборку записей на релевантные и нерелевантные, чтобы оценить качество поиска, а при необходимости уточнила запрос.

**Пропуск не равен отсутствию сведений в действительности.** Некоторые данные могут существовать в других каталогах или в отдельных изданиях, хотя не отображаются в ответе Search API. Для уточнения результатов можно сравнить небольшую выборку записей с данными национальных библиотек или детальными страницами произведений и изданий.

**Исторические даты и сравнение периодов.** Поле `first_publish_year` показывает год, известный Open Library, а не обязательно установленную исследователями дату первой публикации. Кроме того, произведения без года исключены из сравнения эпох, что может влиять на результат. Для проверки следовало бы отдельно исследовать точность годов и состав записей с неизвестной датой.

**Обновления и массовый сбор.** Каталог меняется, а постраничная выдача не является гарантированным снимком базы в один момент времени; повторный запрос может вернуть другое число записей. Для дальнейшего крупномасштабного исследования разумно рассмотреть официальные выгрузки Open Library и сопоставить результаты с API, учитывая, что структура и правила отбора данных в этих источниках могут различаться.
